# 芯光智数微信小程序交付说明

日期：2026-11-11

## 一、代码位置

- 公司仓库：`https://github.com/zyongqiang252-debug/xgsz-web`
- 交付分支：`master`
- 小程序目录：`miniprogram/`

小程序使用原生微信小程序技术栈（WXML / WXSS / JavaScript），不依赖 uni-app，也不包含管理后台。

## 二、页面清单

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 首页 | `miniprogram/pages/home/index` | 品牌首屏、业务入口、产品、服务、行业场景与合作入口 |
| 产品与解决方案 | `miniprogram/pages/products/index` | 四个业务方向、服务器分类、型号与平台入口 |

| 招商合作 | `miniprogram/pages/partners/index` | 合作方向、合作邀请与申请入口 |
| 关于我们 | `miniprogram/pages/about/index` | 项目动态、公司简介、核心业务与服务方式 |
| 联系我们 | `miniprogram/pages/contact/index` | 电话、企业微信、邮箱、地址与咨询入口 |

底部 TabBar 为：首页 / 产品 / 服务 / 关于 / 联系。

## 三、接口与提交方式

| 接口 | 用途 |
| --- | --- |
| `GET /api/public/content` | 读取官网公开页面、产品、服务、合作方向与联系方式 |
| `GET /api/auth/session` | 匿名获取 CSRF token |
| `POST /api/public/inquiries` | 提交业务咨询，携带 `X-CSRF-TOKEN` 和 `consent: true` |
| `GET /api/health` | 检查后端服务状态 |

咨询接口是公开接口，不要求用户登录。提交成功后小程序只显示“需求已提交，我们会根据您留下的联系方式尽快与您沟通”，不展示或承诺回执编号。

## 四、发布前配置

1. 将 `miniprogram/project.config.json` 中的 `appid` 从 `touristappid` 替换为实际小程序 AppID。
2. 将 `miniprogram/config.js` 中体验版和正式版的 `https://your-domain.example.com` 替换为已备案的生产 HTTPS 域名。
3. 在微信公众平台配置合法域名：
   - request 合法域名：后端接口域名
   - downloadFile 合法域名：图片和素材域名
4. 开发阶段可在微信开发者工具中勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。
5. 导入目录选择 `miniprogram/`，不要导入整个仓库根目录。
