## 二、对外展示还缺的资料

按影响从大到小排列。除标注位置外，均可在管理后台对应模块直接填写，保存后刷新官网即可看到。

### 1. 淘宝、抖音线上平台链接（占位链接）

- 当前值：`https://www.taobao.com/`、`https://www.douyin.com/`，是平台首页，不是公司店铺。
- 影响：首页“线上平台”两个入口会把访客带到淘宝、抖音首页，没有实际意义。
- 需要提供：淘宝店铺/商品链接（`https://shop...taobao.com` 或 `https://item.taobao.com/...`）、抖音店铺或账号主页链接。
- 填写位置：后台 → 页面展示 → 业务方向与线上平台。

### 2. 企业微信（联系页显示“暂未公布”）

- 当前值：企业微信名称、二维码、添加链接全部为空。
- 影响：联系页“企业微信”一栏显示“暂未公布”，页脚也不显示企业微信信息。
- 需要提供（三选一或都提供）：
  - 企业微信名称（对外展示的公司/客服名称）；
  - 企业微信二维码图片（PNG/JPG，512KB 以内，长边不超过 2048 像素）；
  - 企业微信“联系我”链接（如果已开通）。
- 填写位置：后台 → 联系方式。

### 3. 联系邮箱、联系地址（留空）

- 当前值：邮箱、地址均为空，官网不展示这两项。
- 需要提供：对外接收咨询的邮箱、办公地址（可写到楼层，是否公开由公司决定）。
- 填写位置：后台 → 联系方式。

### 4. ICP 备案号、公安备案、版权所有者（页脚留空）

- 当前值：备案号、公安备案号、备案图标、版权所有者均为空；页脚版权显示“© 2026 芯光智数”。
- 影响：大陆服务器上线后，页脚没有备案号属于不合规展示。
- 需要提供：ICP 备案号（如“浙ICP备xxxxxxxx号-1”）、公安备案号（如“浙公网安备 xxxxxxxxxxxxxx号”）、备案图标（可选）、公司全称或版权声明。
- 填写位置：后台 → 页面展示 → 备案与版权。

### 5. 合作品牌与授权证书（当前为空，页面不显示该区块）

- 当前值：品牌 0 条、授权证书 0 条。
- 影响：首页“合作品牌”“品牌授权与资质”区块没有内容可展示；涉及品牌授权宣传时，缺少证书会有合规风险。
- 需要提供：合作品牌名称 + Logo（透明 PNG 最佳）、授权证书扫描件（可打码敏感编号）。
- 填写位置：后台 → 页面展示 → 品牌管理 / 授权证书。

### 6. 产品实拍图、具体型号与配置

- 当前值：3 个产品只有方案级描述，没有产品图片；页面使用概念示意图，并注明“整机外观为概念示意”。
- 影响：客户看不到真实机型，也无法判断配置范围。
- 需要提供：主推机型的型号、关键配置（CPU/GPU/内存/存储/网络）、参考价格区间（是否公开由公司决定）、产品实拍图或厂商官方图。
- 填写位置：后台 → 产品管理（逐条编辑）。

### 7. 首页轮播、推荐产品、公司展示图片（当前为空）

- 当前值：轮播 0 条、推荐产品 0 条、公司展示图片 0 条；页面使用内置静态大图。
- 影响：不影响打开，但首页视觉是通用素材，缺少公司自己的办公、机房、交付现场照片。
- 需要提供：3–5 张横版高清图（建议 1920×1080 以上）、希望在首页推荐的产品。
- 填写位置：后台 → 页面展示 → 首页轮播 / 推荐产品 / 公司展示图片。

### 8. 关于我们的公司信息与项目动态

- 当前值：公司介绍为通用业务描述；“项目动态”4 条记录的是本次网站建设过程（2026-11-05 至 11-10）。
- 影响：对外发布后，客户看到的“动态”是建站记录，不是公司经营动态。
- 需要提供：公司成立/团队规模/服务客户数量等可核实信息、真实项目或交付案例、希望展示的时间线节点。
- 填写位置：后台 → 页面展示 → 公司介绍。

### 9. 管理员账号

- 当前值：0 个管理员。
- 说明：首次打开 `/admin.html` 会要求创建账号，密码至少 12 位，创建后该入口关闭。请由公司指定人员创建并妥善保管，不要使用公共弱密码。

## 四、当前功能边界（明确没有的能力）

- 不提供客户注册、客户登录、在线下单与在线支付，官网只做展示与需求收集。
- 咨询提交后只写入数据库，**不会**发送短信、邮件或企业微信通知；需要管理员登录后台「咨询记录」查看。
- 没有在线客服/IM 挂件；对外沟通依赖电话、邮箱与企业微信。
- 没有多语言版本，没有英文站。
- 图片上传限制 5MB，支持 PNG/JPEG/BMP，保存在数据库中。
- 微信小程序需要单独配置 AppID、服务器合法域名（HTTPS）并提交审核，审核通过前只能开发者工具预览。
- 后台账号只有一套管理员体系，没有角色分级与操作审计日志。
