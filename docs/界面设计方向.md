# 芯光智数界面升级

本次使用 frontend-design 与 ui-ux-pro-max。设计检索中“enterprise computing”偏向科幻 HUD，与企业采购及运营场景不符，已用 B2B enterprise dashboard accessible 重新检索，采用高可读性、清晰导航及可见状态建议，而不套用其通用调色。

品牌色保留芯光 Logo 的蓝青关系：深海蓝 #102D40、品牌蓝 #1263CC、交互青 #007F79、浅灰 #F3F6F8、正文 #203945、次要正文 #536873。危险操作单独用 #B43434。界面正文以 15–16px 为基准；中文使用系统等线 / 微软雅黑，数字和拉丁文字使用 Segoe UI，避免依赖远程字体加载。

官网继续以算力机房主视觉为唯一强视觉元素；产品信息靠字号、留白和真实分类分层。删去非顺序内容的编号、重复英文眉题和多余的宣传句。按钮说明下一步动作，咨询明确显示提交、失败与收到确认。

后台以待处理咨询、已上架内容、最近需求和编辑操作为核心，不再放大幅品牌宣传卡片。侧栏固定识别当前位置；列表按钮保持至少44px的触达高度。登录页用品牌与账号表单两栏，手机上优先表单。

布局：

```text
官网：品牌导航 → 机房与业务主张 → 产品选择 → 服务范围 → 场景 → 咨询
后台：侧栏 | 标题与操作 → 待办和内容统计 → 最近咨询 / 上架内容
登录：品牌说明 | 首次创建管理员 / 账号登录
```

相较旧版，本轮刻意保留品牌与业务图像，取消后台装饰芯片和重复英文标签，把差异化用在服务器产品分类与服务边界的可读呈现上。未使用 React/Next.js，因此不引入不适用的 React 优化流程。
