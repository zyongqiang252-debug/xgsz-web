# 现行接口与后续工作

本文件已替代旧的纯前端计划。当前项目已在本地接通，运行入口与源码复用范围详见 [运行与后台使用](运行与后台使用.md)。

## 现行接口

统一成功响应为原项目 `BaseResponse` 的 `{code:0,message:"success",data:...}`；错误同时返回相应 HTTP 状态。所有写操作都需通过 `/api/auth/session` 取得的 CSRF Token，放在 `X-CSRF-TOKEN` 请求头。

| 路径 | 行为 |
| --- | --- |
| GET /api/health | 服务与持久化存储标识 |
| GET /api/auth/session | 当前会话、是否需要首次设置、CSRF token |
| POST /api/auth/setup | 仅未创建管理员时可用 |
| POST /api/auth/login、/api/auth/logout | 登录与退出 |
| GET /api/public/content | 仅上架产品 / 服务与企业联系信息 |
| POST /api/public/inquiries | 校验后将需求与同意记录写入数据库；小程序端只显示提交成功，不展示回执 |
| GET /api/admin/content | 登录后读取全部内容与版本 |
| POST /api/admin/products、/api/admin/services | 新增内容 |
| PUT /api/admin/products/{id}、/api/admin/services/{id} | 携带 version 更新，冲突返回409 |
| DELETE /api/admin/products/{id}?version=…、/api/admin/services/{id}?version=… | 版本校验后删除 |
| PUT /api/admin/settings | 企业联系信息，需携带version |
| GET /api/admin/inquiries | 登录后读取咨询 |
| PATCH /api/admin/inquiries/{id} | 标记 pending / done |
| GET /api/admin/system | 登录后只读读取数据库类型、数据表、初始化标记和页面版本；不返回连接密码 |

## 已落地

原产品服务 / MyBatis 与 Products 表的实际复用；专用 Spring Boot 构建；MySQL 持久化；管理员安全初始化、会话登录和退出；服务内容与站点配置；咨询留资及处理；前后端校验；CSRF、基础限频；内容版本冲突检查与一致读取；失败保留输入；浏览器与重启持久化验证；通用 Nginx 与 systemd 部署模板。

## 仍需业务资料与发布条件

真实企业全称与联系信息、确定的在售整机型号和实拍图片、可公开资质、服务合同边界，以及公网域名 / 备案 / HTTPS。当前没有配置邮件、短信、企微通知，不会声称已自动通知销售人员。

仓库已提供 `miniprogram/` 原生微信小程序公开页，复用 `/api/public/content`、`/api/auth/session` 和 `/api/public/inquiries`，不包含管理后台。发布前仍需配置实际 AppID、已备案的 HTTPS 域名和微信公众平台合法域名，并在真机验证 Cookie、CSRF、拨号与复制能力。

运行环境使用 MySQL，H2 仅为 Java 单元测试依赖。完整建库、建表和初始内容见 [数据库说明](../database/README.md)，公司环境配置、备份与更新方式见 [部署说明](部署说明.md)。

## 联系方式字段扩展（2026-11-06）

现有 `/api/admin/settings` 与 `/api/public/content` 的 `settings` 增加 `wecomName`、`wecomUrl`、`wecomQr`，与 phone/email/address/version 一同存储，旧数据库读取时补空默认值，无需手工迁移。QR为经校验并重新编码的 PNG Data URL，支持空字符串清除。修改仍需管理员会话、CSRF与设置版本。新增公开联系路由 `/#/contact`；联系页、页脚与咨询弹窗使用同一组件，兼顾直接联系与留资。
